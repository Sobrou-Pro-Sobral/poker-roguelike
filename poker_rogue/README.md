# Poker Roguelike

Projeto Flutter de um jogo single-player de Texas Holdem com fluxo inicial de
poker roguelike.

## Como executar

Para rodar no navegador:

```bash
flutter run -d chrome
```

Para rodar no Android, selecione um emulador ou celular conectado e execute:

```bash
flutter run
```

## API usada

O projeto usa a Deck of Cards API para criar/embaralhar o baralho e comprar
cartas durante a partida.
